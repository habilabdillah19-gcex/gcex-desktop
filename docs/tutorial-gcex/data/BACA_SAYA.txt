DATA LATIHAN GC-Ex — SEPENUHNYA SINTETIS
========================================
Semua angka di folder ini dihitung dari model matematika (lihat make_sim_data.py).
TIDAK ada nama perusahaan, Hole ID, koordinat, atau hasil lab proyek nyata.

Mulai dari mana
---------------
1. Latihan cepat  : SIM_kecil_collar.csv / _survey / _assay / _geologi  (164 bor)
2. Data penuh     : SIM_collar.csv / _survey / _assay / _geologi        (610 bor, 76069 baris assay)
3. Topografi      : SIM_topo_xyz.csv        (Data Spasial -> topografi)
4. Block model    : SIM_BM_GC.csv           (KOSONG -> GC-Ex Drill Hole: Model Estimation)
                    SIM_BM_GC_kadar.csv     (BERISI kadar -> GC-Ex Block Model: flitch, dig block, as-mined)
5. Struktur       : SIM_struktur.csv        (basis data struktur: Dip, Dip_Azimuth, Plunge, Trend)
   Pick-up permukaan: SIM_pickup_survey.csv (Peta / Mapping)
6. Sesar 3D       : SIM_sesar.csv           (post-mineralisasi, offset 12 m)
7. QAQC           : SIM_qaqc.csv            (CRM, duplikat, blank)
8. Wireframe      : QV_Lensa2_Leapfrog.obj  (uji import solid dari luar)
10. Block model + hasil estimasi : SIM_BM_GC_estimasi.csv
    Sama dengan SIM_BM_GC_kadar.csv, ditambah kolom hasil Model Estimation GC-Ex Drill Hole:
    est_pass, est_nsamp, est_sor, est_ke, est_nhole, est_spasi, est_type, sb_frac, domain_est.
    Dipakai di GC-Ex Block Model untuk melatih:
      - Reporting BM: pembobotan proporsi volume sub-blok (sb_frac). 20,1% blok bernilai < 1,
        jadi tonase dengan pembobotan jelas lebih kecil daripada tanpa pembobotan.
      - membaca block model yang berasal dari estimasi Drill Hole.
    Dibuat ulang dengan: python docs/tutorial-gcex/tambah_est_bm.py  (hasilnya selalu sama).
    Angka est_* di berkas ini TIRUAN; untuk latihan estimasi sebenarnya pakai GC-Ex Drill Hole.

CARA MELATIH LAPORAN PERIODE (mingguan / bulanan) di GC-Ex Block Model
    Laporan periode membaca register as-mined, yang poligonnya Anda digitasi sendiri -- jadi tidak
    bisa disiapkan sebagai berkas. Latihan tercepat:
      1. Import SIM_BM_GC_kadar.csv, tetapkan flitch, buat beberapa dig block.
      2. Menu As-Mined: digitasi 2-3 poligon, isi tanggal & shift (DS / NS), jalankan As-Mined.
      3. Pindah ke flitch di bawahnya, ulangi dengan TANGGAL BERBEDA.
      4. Project Tree > Register & Laporan As-Mined > Laporan periode: pilih "Bulan ini",
         kelompokkan per tanggal / shift / flitch. Isi target ton untuk melihat pencapaiannya.
9. Upsert         : SIM_upsert_*.csv / SIM_upsert2_*.csv  (bor baru tahap 1 & 2, estimasi ulang sebagian)

Set latihan lain
----------------
SIM_gc_*.csv          kampanye GRADE CONTROL: bor tegak per bench, pola 7 m (459 bor, 22361 baris assay)
SIM_split_*.csv       vein BERCABANG (lensa 2 + splay hangingwall) + SIM_split_BM_GC.csv blok 2,5 m
SIM_rusak_*.csv       database dengan kesalahan SENGAJA (latihan menu Validasi data bor):
                      collar -> Hole_ID ganda, kedalaman 0, koordinat kosong, koordinat di luar area
                      assay  -> From=To, interval tumpang & Sample_ID ganda, Hole_ID tak ada di
                                collar, nilai -99, interval melebihi kedalaman bor
SIM_topo_xyz_nov.csv  topografi survei berikutnya (area tambang turun s/d 7 m) -> latihan versi
                      topografi di Data Spasial dan perhitungan volume sisa
SIM_LAT_*.csv         endapan LATERIT berlapis (dibuat make_sim_laterit.py) untuk menu
                      Geomodeller Stratified-Laterite Deposit

Catatan: wireframe contoh kini bernama QV_Lensa2_Leapfrog.obj (dulu QV_Utama_Leapfrog.obj),
karena model vein sekarang berupa array 4 lensa, bukan satu vein tunggal.
