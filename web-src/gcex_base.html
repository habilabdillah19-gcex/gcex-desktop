Buat titik di peta

Pilih alat, lalu klik di peta plan. Garis: tarik. Grid: klik sudut-sudut area, klik ganda untuk selesai. Shift+klik: hapus titik.

Digitasi string

Klik kiri di Penampang 2D: tambah titik (Z / bidang terkunci pada slab aktif). Klik titik pertama: string tertutup. Enter: selesai · Backspace: hapus titik · Esc: batal. Drag tetap untuk menggeser peta.
Export string ke Surpac ada di Layout & Ekspor Dig Plan › Export STR / DXF, dan berlaku untuk flitch yang sedang aktif.

Import Wireframe Geologi

Wireframe / solid geologi diimport lewat baris + Tambah wireframe geologi… di Project Tree (paling bawah node Import Wireframe Geologi). Setiap berkas muncul di sana sesuai urutan import.
Format: Leapfrog .msh · Surpac .dtm (pilih bersama file .str-nya) · DXF 3DFACE / polyface · Wavefront .obj. Saat slab dipotong / Penampang 2D, model tampil sebagai garis perpotongan.

Data referensi (permukaan DTM, titik survey, string)

Semua data referensi diimport lewat baris + Tambah data referensi… di Project Tree (paling bawah node Data Referensi).

Permukaan pit / topografi (DTM)

Desain pit dan survei topografi berupa DTM segitiga (Surpac .dtm + .str, DXF 3DFACE), dipakai di Reporting › Pit & progres dan sebagai batas DTM. Wireframe geologi diimport di node Import Wireframe Geologi.

Titik survey pemetaan lapangan

Kolom X/Easting, Y/Northing, Z/Elevasi (tanpa Z: diambil dari topografi), ID titik dan kolom keterangan / kode untuk pewarnaan.

String Surpac / DXF

Surpac .str (teks / binary) atau .dxf (LINE / POLYLINE / LWPOLYLINE): desain, oreline, kontak geologi, dsb. Di sayatan hanya bagian di dalam slab yang tampil, kecuali opsi proyeksi dinyalakan. Tombol → Dig menyalin string tertutup ke daftar Digitasi / dig block.
